  \begin{alertblock}{Key Result --- Causal, Not Just Correlated}
    \begin{center}
      \vspace{-0.1em}
      {\fontsize{180}{195}\selectfont\textbf{10.1\,\%}}\\[0.2em]
      {\LARGE of agent tool choices \textbf{reverse}}\\[0.1em]
      {\LARGE when 10 SAE features are ablated.}\\[0.5em]
      {\large \emph{Removing a handful of features
                    \textbf{causally changes} the agent's tool choice.}}\\[0.5em]
      {\large random ablation: \textbf{0\,\%} \quad$\cdot$\quad
              SAE round-trip: \textbf{0\,\%} \quad$\cdot$\quad
              $p = 0.002$}\\[0.3em]
      {\normalsize \emph{up to 17.1\,\% on other contrast types.}}\\[0.4em]
      {\footnotesize \emph{fundamental vs.\ technical analysis} (finance
       domain, 1 of 23 contrast types tested) ---
       Nemotron-3-Nano-30B, layer 20.}
      \vspace{-0.1em}
    \end{center}
  \end{alertblock}

  \begin{block}{The Tool-Selection Black Box}

    \large
    Modern AI agents autonomously pick among databases, code, web search, and
    sub-agents. When the agent chooses, \emph{why} it chose remains opaque.

    \begin{itemize}
      \item \textbf{Prompt engineering:} correlational, not causal.
      \item \textbf{Behavioural testing:} input/output only.
      \item \textbf{Chain-of-thought:} plausible, often confabulated.
    \end{itemize}

    We open the black box at the token where the model commits to a tool and
    decompose its hidden state into human-readable features.

  \end{block}

    \end{center}

    \vspace{0.4em}
    {\Large\textcolor{fdark}{\textbf{$\blacktriangle$ Activates on}}}\\[0.15em]

    \heading{\Large Behaviour under ablation}

    \large
    \begin{tabular}{@{}r@{\,\,}c@{\,\,}l@{}}
      Write request, feature \emph{intact}    & $\Rightarrow$ & agent picks \texttt{[file\_write]}\\[0.15em]

    \vspace{0.5em}
    {\small Features like this emerge \emph{without} contrastive supervision

  \begin{block}{Scope \& Limitations}
    \begin{itemize}
      \item One model (Nemotron-3-Nano-30B), one layer, one decision-token
            convention.
      \item Top-10 ablation is conservative; distributed decisions need
            larger sets.
      \item Feature labels rely on Qwen3-VL-235B --- judge errors propagate
            to rationales.
    \end{itemize}
  \end{block}

  \begin{exampleblock}{Why This Matters in Production}

    \begin{figure}
      \centering
      \includegraphics[width=0.74\linewidth,keepaspectratio]{images/inference_pipeline.png}
      \caption{\textbf{Every tool call ships with a rationale.}
        At inference, the top-$K$ active features at the decision token
        map to pre-computed labels --- a human-readable explanation
        alongside the tool choice, with no extra LLM call.}
    \end{figure}

    \large
    Most SAE work stops at finding features. Here the features
    \textbf{ship to inference}: every tool call carries a top-$K$ feature
    rationale alongside it --- a \textbf{debugging surface} for deployed
    agents, and a foundation for \textbf{future anomaly detection} when
    activations deviate from a tool's normal fingerprint.

  \end{exampleblock}

    \end{itemize}

  \begin{alertblock}{Causal Ablation}

    \begin{figure}
      \centering
      \includegraphics[width=0.92\linewidth,keepaspectratio]{images/chart_ablation.png}
      \caption{\textbf{Ablating SAE features changes tool decisions ---
        random features do not.} Top-10 contrastive features vs.\ random
        features vs.\ SAE round-trip baseline.}
    \end{figure}

    \large
    \heading{Where it works (and where it doesn't)}

    \begin{itemize}
      \item \textbf{Works:} \emph{fundamental} vs.\ \emph{technical} ---
            10.1\,\% flip, controls 0\,\% ($p=0.002$).
      \item \textbf{Works:} \emph{single} vs.\ \emph{multi-tool} ---
            17.1\,\% vs.\ 2.4\,\% ($p=0.029$).
      \item \textbf{Null: 9 of 23 contrast types show zero flip
            rate.}\\ Those decisions are encoded \emph{distributively}
            across many features, not localized in a sparse circuit.
            A known boundary --- and a checklist item for replications.
    \end{itemize}

    \heading{Why the effect is real}
    Random-ablation flip rate \emph{equals} SAE round-trip distortion across
    all 23 contrast types. The contrastive flip is \textbf{above} this noise
    floor --- it must come from the specific features removed, not from
    encode/decode artefacts.

  \end{alertblock}

Same words, different framing — steering a support agent's tool choice

Six pairs of customer-support requests where the tool the agent picks turns on how the request is framed, not on which words it uses. The sharpest pair contains the same content words in a different order — “I was billed for a feature I can't find” goes to the billing system, “I can't find the feature I was billed for” goes to customer history — and three of the six themes have no distinguishing word at all. For each pair: the tool distribution on both sides, the SAE features specific to each side, what happens when those families are switched off, and whether clamping one side's features into the other request — prompt untouched — moves the decision across. It does: eight of twelve sides flip under ablation, four cross-patch directions flip the recipient's tool, and in three of them the model goes on to write a different tool name. Read at layer 34: layer 43, which carries the decision in the other scenarios, is degenerate here — 1,162 features fire on every prompt and only 32 vary.

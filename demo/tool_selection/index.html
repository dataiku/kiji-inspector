One cue, one flip — what the SAE says about a tool choice

Pairs of near-identical requests where changing one cue changes the tool the model picks. For each pair: the model's tool distribution on both sides, the SAE features that are specific to each side (the cue features), what happens to the decision when each cue family is switched off on its own side, whether patching one side's cue families into the other side moves the decision across — and, where the trace was run, where in the prompt those features live, how much of them is needed, and what the model then writes.

The Inference Auditor

A repair agent reads a customer's complaint and picks a tool. This page opens the model at that exact moment — which of its sparse-autoencoder features fire, and what they claim it is reading into the request. Then it tests every one of those claims by changing a single word of the request and watching what moves. Readings that survive are marked; so are the ones that don't, and so is an alarm we tried to build out of these features and couldn't. The demo where these features move a real decision is tool selection.

A sweep of this scenario's own training pairs (743 anchor/contrast duos, all five configured contrast dimensions, output/sweep/training_pairs_flips.json) found zero pairs where the model's first tool flips between the two sides — every request states its ask, and the ask decides the tool. There is nothing here for a feature-level intervention to flip, so the null above is what an honest instrument reports on this scenario.

On the scenario that does have flippable pairs (tool selection: 7,478 pairs, 44.7% flip), the same ablation battery shows description early and leverage late — layer 27 already moves 6 of 14 sides beyond the control band yet flips nothing; the first cross-patch flips appear at layer 34 and effect sizes keep growing to layer 43.

How to read this page
  1. Pick a problem below.
  2. Decision snapshot: the tool the model chose (next-token probabilities at I'll use the) and the SAE features that stood out, with raw activation and how far above the three-problem average each one is. Not stated in request marks features whose specific content the request never mentions.
  3. Contrast: the same request with one phrase changed — which features appear, disappear, or shift, and whether the tool choice moves.
  4. Causal check: selected features switched off or clamped at the decision token, and the tool distribution re-read (HuggingFace backend, caveats shown).
  5. Scroll down for the training contrast dimensions scored from every active feature via the training contrastive map.
